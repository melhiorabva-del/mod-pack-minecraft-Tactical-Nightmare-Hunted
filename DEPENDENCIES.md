# DEPENDENCIES

Liste des APIs et dépendances à vérifier et inclure dans le dossier `mods/` si nécessaire :

- Curios API (ex: curios-forge)
- GeckoLib (geckolib-forge)
- Cloth Config (cloth-config)
- KotlinForForge (kotlinforforge)
- Embeddium (embeddium)
- JEI (if not included)
- Forge-compatible versions of ModernFix / Starlight / FerriteCore / EntityCulling

Notes :
- Vérifier toujours sur la page CurseForge / Modrinth que la build est explicitement listée pour Minecraft 1.20.1 et pour Forge.
- Certains mods (MCreator exports) peuvent avoir des dépendances ou comportements spécifiques — testez en instance propre.
