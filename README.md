# mod-pack-minecraft
Tactical Nightmare
Un modpack de survie et d'horreur hardcore, pensé pour vous traquer sans pitié tout en vous donnant les moyens de vous défendre férocement. Conçu pour tourner de manière fluide même sur des petites configurations (jouable avec seulement 2 Go de RAM grâce à une optimisation poussée).

🎮 Le Concept
Vous êtes plongé dans un monde sombre où des créatures cauchemardesques vous traquent en permanence (The Man From The Fog, CaveDweller, Born in Chaos, etc.). Pour survivre, l'artisanat de base ne suffira pas : vous disposez d'un arsenal militaire moderne ultra-poussé via TACZ (Timeless and Classics Zero), de tourelles de défense et de PNJ armés pour tenir tête à la horde.

⚙️ Performances & Configuration
Version : Minecraft 1.20.1 (Forge)

RAM recommandée : 3 Go minimum (le pack intègre un pack d'optimisation lourd : ModernFix, FerriteCore, Embeddium, Starlight, etc. pour garantir un 30 FPS stable sans micro-saccades). 
              
:4 a 5 go pour du vrai stabilité en minimum 60 fps (testé pas mon pc super faible qui peut avoir 3 ram alloué)
