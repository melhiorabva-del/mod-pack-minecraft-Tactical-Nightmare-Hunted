# mod-pack-minecraft
Tactical Nightmare
Un modpack de survie et d'horreur hardcore, pensé pour vous traquer sans pitié tout en vous donnant les moyens de vous défendre férocement. Conçu pour tourner de manière fluide même sur des machines modestes.

🎮 Le Concept
Vous êtes plongé dans un monde sombre où des créatures cauchemardesques vous traquent en permanence (The Man From The Fog, CaveDweller, Born in Chaos, etc.). Pour survivre, l'artisanat de base et l'ingéniosité sont essentiels — mais vous aurez aussi des outils et des armes pour vous défendre.

⚙️ Performances & Configuration
Version : Minecraft 1.20.1 (Forge)

RAM recommandée : 3 Go minimum (le pack intègre un pack d'optimisation lourd : ModernFix, FerriteCore, Embeddium, Starlight, etc. pour garantir un 30 FPS stable sans micro-saccades).

:4 a 5 go pour du vrai stabilité en minimum 60 fps (testé pas mon pc super faible qui peut avoir 3 ram alloué)

## Configuration testée (profil de l'auteur)
- Forge : 1.20.1
- RAM allouée : 3 GB
- Render distance (affichage) : 15
- Simulation distance : 15
- Durée du test : 8 heures de jeu en continu
- Résultat : 60 FPS stables sans chute ni bug constaté
- Launcher utilisé : non précisé (précisez si vous voulez que je l'ajoute)

Remarque : ces réglages correspondent à la configuration utilisée par l'auteur pour tester le modpack. Ils permettent de reproduire l'expérience exacte décrite ci‑dessus. Si vous jouez sur une machine plus limitée, réduisez la render/simulation distance à 8–12 ou allouez plus de RAM (4–5 GB) pour des mondes plus chargés.
