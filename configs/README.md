# Configs recommandés

Ce dossier contient des recommandations et snippets à appliquer dans le dossier `config/` de votre instance Minecraft. Ces fichiers sont des suggestions — vérifiez les noms de clés exacts dans les fichiers `config` générés par les mods et adaptez si nécessaire.

Procédure d'utilisation rapide :
1. Créez une instance séparée (MultiMC/CurseForge) pour tester les réglages.
2. Placez les fichiers de configuration finaux dans `<minecraft>/config/` avant de lancer le jeu.
3. Gardez une copie des fichiers originaux pour revenir en arrière.

Fichiers inclus :
- modernfix-recommended.txt
- starlight-recommended.txt
- ferritecore-recommended.txt
- entityculling-recommended.txt
- JVM-ARGS.txt

Note : ces snippets sont indicatifs. Les clés exactes peuvent varier selon la version du mod.
